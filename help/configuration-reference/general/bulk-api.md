## [!UICONTROL General]

| Campo | [Ámbito](../../getting-started/websites-stores-views.md#scope-settings) | Descripción |
|--- |--- |--- |
| [!UICONTROL Maximum Entities Per Bulk Request] | Global | Muestra el número máximo de entidades que se pueden procesar en una única solicitud masiva. Se recomiendan [API en lotes](https://developer.adobe.com/commerce/webapi/rest/use-rest/bulk-endpoints/){target="_blank"} para combinar varias llamadas en una sola solicitud a fin de reducir la cantidad de solicitudes y mejorar el rendimiento. Los clientes pueden solicitar un aumento de [!UICONTROL Maximum Entities Per Bulk Request] poniéndose en contacto con el [Soporte técnico de Adobe Commerce](https://experienceleague.adobe.com/es/support?support-tab=home#support). Adobe revisará su caso de uso y determinará si es adecuado aumentar el tamaño de la solicitud masiva. |
